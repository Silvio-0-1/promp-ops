# Tooling Landscape

A non-exhaustive list of platforms commonly used in PromptOps work:

| Platform | Strengths |
|---|---|
| **Braintrust** | End-to-end: prompt registry, evals, experiments, observability. |
| **PromptLayer** | Prompt versioning + logging, popular with OpenAI users. |
| **Langfuse** | Open-source tracing and evals. |
| **LangSmith** | Tight integration with LangChain. |
| **Maxim AI** | Evaluation pipelines and experimentation. |
| **Vellum / PromptHub** | Prompt management and collaboration. |
| **Future AGI** | Eval-focused tooling. |

Pick based on your stack, hosting requirements (cloud vs. self-hosted), and whether you need a full lifecycle platform or just one piece.
