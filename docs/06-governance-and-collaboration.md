# Phase 6 — Governance & Collaboration

Across every phase, enforce:

- **Access control** — RBAC + SSO so only authorized users edit or deploy prompts.
- **Audit logs** — who changed which prompt, when, and why.
- **Review workflows** — pull-request-style approval before a prompt version goes live.
- **Data handling policies** — PII redaction, retention windows, regional storage.
- **Responsible AI checks** — bias, safety, and content-policy reviews.
- **Documentation** — every prompt should have an owner, a purpose, and known limitations recorded.

Governance is not a single phase — it is a thread that runs through design, versioning, evaluation, deployment, and monitoring. Treat prompts as production assets with the same controls you apply to code and data.
